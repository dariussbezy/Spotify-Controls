# Spotify Controls

Control Spotify from a player above the YouBar, with search, queue and animated waves.

- Play, pause, skip, seek and shuffle/repeat from a compact or expanded player.
- Search Spotify, then play now, play next or add to the queue.
- Drag the player between closed, compact and expanded, or swipe it away for the session.
- Optional player that stays when nothing is playing.

Uses the Spotify account linked in Discord. Some controls need Spotify Premium.
